# Ledge v1.0.0

Windows 10 / 11 桌面边缘液态毛玻璃灵动岛首个正式发布版本。

---

## 全功能一览

### 1. 灵动岛本体与外观皮肤
- **四边吸附与液态交互**：支持屏幕顶部、底部、左侧、右侧边缘任意停靠，支持按住拖拽、拉断液桥及自动吸附；支持悬停展开 / 常驻展开 / 保持收起模式与可穿透模式。
- **动态帧率节能**：交互与展开动画期间以 **60 FPS** 流畅渲染，收起态静止呼吸时自动降至 **30 FPS** 节能。
- **5 套内置皮肤**：深色毛玻璃（`dark`）、浅色毛玻璃（`light`）、晴空渐变（`sky`）、胭脂撞色（`rouge`）、经典纯黑（`classic`），并支持随系统深浅自动切换。
- **收起态视图轮换**：支持在「时间与天气」「可交互小形象」「音乐播放」之间定时自动轮换或鼠标滚轮瞬切。

### 2. 收起态时间字体与配色定制
- **7 种固定时间字体风格**：简约、矢量 7 段数码管（含微发光与暗底槽）、霓虹（Orbitron）、衬线斜体（Instrument Serif）、宽体（Unbounded）、窄体（Bebas Neue）、圆润（Fredoka），采用固定数字槽宽防止时间跳动抖动。
- **8 种配色方案**：主题默认色、琥珀、青色、粉色、柠檬绿、跟随音乐封面提取主色、自定义拾色器、水平线性渐变（含精选渐变预设）。
- **主题对比度自适应**：依据深色/浅色/天空背景自动微调颜色亮度，确保在任何皮肤下清晰易读；并支持关闭「收起态显示天气」以仅居中展示纯净大时间。

### 3. 首页、音乐控制与小形象
- **媒体联动控制**：左侧紧凑展示专辑封面、单行自适应「标题 · 歌手」、进度条与起止时间、上一首 / 播放暂停 / 下一首；支持网易云音乐本地日志精准进度。
- **收起态音乐视图**：播放时可自动切入音乐胶囊，展示封面、动态律动波形与实时同步歌词。
- **灵动小形象**：右侧双眼实时跟随光标移动，鼠标靠近触发多种互动表情，新消息到达时触发惊讶反应。

### 4. 天气预报与收起态矢量联动
- **收起态矢量同步**：采用 1.55px 精致线条矢量天气图标（覆盖晴/夜/少云/多云/雨/雷暴/雪/雾），温度数字同步当前时间字体风格与柔和色调。
- **展开态天气面板**：支持多城市管理与快速切换，默认免 Key 接入 Open-Meteo（可选配 OpenWeather）；展示当前温度、温差与体感、4 列对齐气象指标（湿度、能见度、风速风向、气压、云量、日出日落）、未来 5 天温差条与可滚动逐小时预报。

### 5. 邮件监听与验证码识别
- **多账号 IMAP 监听**：支持 IDLE 实时推送与失败自动降级轮询；支持按账号筛选、全部/未读切换、本机已读状态管理及可选服务器同步。
- **安全纯文本预览与自动复位**：邮件详情以安全纯文本展示并做本地正文缓存；从详情页收起灵动岛后再次展开时自动回到邮件列表。
- **验证码快捷卡片**：收到验证码邮件时在岛侧展示 180 秒大字验证码预览卡，支持一键复制。

### 6. AI 额度监控
- **5 家服务商真实查询**：支持 **DeepSeek**（API Key 余额）、**WorkBuddy**（官网授权积分/资源包）、**Codex**（只读本机凭据查询 5 小时/周周期）、**Gemini**（网页会话登录额度）、**Grok Bot**（PKCE 授权周额度）。
- **安全与容错**：所有凭据均保存在 Windows 凭据管理器中，绝不写入配置文件或日志；未连接任何账号时自动隐藏额度页；离线或限流时保留最近有效快照并标注状态。

### 7. 日中实时双语字幕
- 捕获系统音频（Loopback）或麦克风语音，通过本地离线识别模型（Parakeet + Silero VAD）完成日语语音识别并实时翻译为中文双语字幕。
- 说话时在收起态以加宽双行胶囊实时滚动显示，安静后自动回到原视图；首次使用支持断点续传下载离线识别模型（约 630 MB）。

### 8. 效率工具与生活提醒
- **文件置物架**：支持拖放本地文件暂存、拖出到其他应用或一键打开。
- **文字剪贴板历史**：自动记录近期文字剪贴板并支持置顶与一键回写，自动排除常见密码管理器等敏感来源。
- **生活提醒**：支持轻量待办清单（含重复提醒）、每日喝水进度与定时提醒、久坐间隔与午休免打扰时段，触发时在岛内弹出轻量浮层。

### 9. Windows 系统通知集成
- 读取 Windows 通知中心消息，支持 QQ、微信与邮件提醒；展开态旁提供 QQ / 微信未读快捷角标，支持点击聚焦客户端与切回前台自动清除；支持免打扰与任务栏闪烁兼容。

### 10. 设置中心、更新检查与崩溃诊断
- **7 大分类设置窗口**：独立浅色/深色主题、支持「保存 / 取消」草稿事务校验与原子写入、支持开机自启、全局快捷键及页面顺序/可见性自定义。
- **数据维护与备份**：支持直接编辑/重载 `config.json`、配置导入导出与出厂默认恢复（自动备份原配置）。
- **版本更新与诊断**：支持在「关于」页主动检查 GitHub Releases 新版本；内置 `faulthandler` 与异常崩溃日志落盘，支持一键导出**自动脱敏**诊断包（剔除用户名路径、邮箱与密钥）。

## 安装、升级与卸载

- **安装版（推荐）**：下载 `Ledge-Setup-v1.0.0.exe` 运行向导（单用户免 UAC 安装至 `%LOCALAPPDATA%\Programs\Ledge`）；覆盖安装自动保留原有 `config.json` 与 `data/`。
- **便携版**：下载 `Ledge-portable.zip` 解压至任意目录，确保 `Ledge.exe` 与 `_internal` 同级，双击 `Ledge.exe` 启动；升级时退出应用覆盖解压即可。
- **彻底卸载**：
  - 安装版可通过 Windows「设置 → 应用」直接卸载（向导末尾可选择是否一并删除 `config.json` 与 `data/`）；
  - 若曾开启开机自启或登录过邮箱/AI 账号，建议先关闭自启并在 Windows 凭据管理器删除 `wisland:*` 凭据后再删除程序目录。
